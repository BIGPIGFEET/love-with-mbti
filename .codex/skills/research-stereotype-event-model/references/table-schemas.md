# Table Schemas and Quality Checks

## Source and Query Ledger

| Platform/source cluster | Query or route | Result | Direct URL | Access/status | Notes |
|---|---|---|---|---|---|

Record blocked login, paywall, or unavailable results as evidence limitations. Do not silently substitute a different platform.

## Feature-Evidence Table

| ID | Neutral observable tendency | Source IDs | Source types | Online-discourse confidence | Creative value | Risk/qualification | Permitted use |
|---|---|---|---|---|---|---|---|

Use source IDs that resolve to the source ledger. Confidence describes repeated online representation, never prevalence in the target population.

## Behavior Model

| Stage | Observable behavior | Constructive potential | Risk/constraint | Player-facing interpretation to avoid |
|---|---|---|---|---|

Assign a feature to a stage only when the source evidence or bounded creative inference makes the timing plausible.

## Conflict Dictionary

| ID | Tension | Legitimate need A | Legitimate need B | Misuse to avoid |
|---|---|---|---|---|

Phrase tensions as competing needs, not as a correct side and a defective side.

## Candidate Event Mapping

| ID | Stage | Situation | Conflict IDs | Feature IDs | Primary state variables | Player agency | Narrative guardrail |
|---|---|---|---|---|---|---|---|

Before promoting an event to production content, specify dialogue, choices, immediate consequences, and the reason each state change follows from behavior.

## Audit Checklist

- Every high-confidence feature has more than one independent supporting cluster when feasible.
- All low-confidence memes are decorative only; they do not determine scoring, morality, or endings.
- At least one counter-stereotype or limitation accompanies each core negative trope.
- Event conflicts are not duplicates under different wording.
- Stage transitions do not imply intimacy, commitment, or consent without explicit evidence in the story.
- A refusal, boundary, or request for clarity is not automatically penalized as "boring," "controlling," or hostile.
