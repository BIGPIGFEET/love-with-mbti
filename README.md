# Love with MBTI

一款面向熟悉 MBTI 的年轻用户的网页文字小游戏。玩家代入自己，与一个由网络刻板印象构成的 MBTI 模拟对象互动，通过十道带有冲突和取舍的题目，观察双方能否从初识走向暧昧或恋爱。

MBTI 在本项目中是传播入口和角色标签，不是心理诊断工具。游戏核心是：面对鲜明且带有戏剧性的相处模式，玩家如何选择，以及这些选择如何改变双方关系。

## 当前状态

`v0.1.0` 第一版最小可玩示例已于 2026-08-11 完成，并通过全部已知路线的人工试玩、外部目标用户调研与移动端/桌面端浏览器验收，暂未发现阻塞问题。

在线访问：[https://mbti.muzichengshan.dpdns.org/](https://mbti.muzichengshan.dpdns.org/)

第一版包含 React + Vite 网页、ENTP 固定十题、正式 TypeScript 数据、全路径平衡验证和“关系事件记录单”纸张视觉，不包含账号、排行榜、角色立绘、音效或付费功能。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器启动后访问终端显示的本地地址（通常是 `http://127.0.0.1:5173`）。

## 检查、测试与构建

```bash
npm run check
npm test -- --run
node scripts/validate-content.mjs
node scripts/analyze-question-paths.mjs
npm run build
```

生产构建输出位于 `dist/`。

## 可复现演示路径

以下选项位置可完成十题并进入“确认恋爱 / 稳定发展”结局：

```text
A → A → A → B → A → B → A → A → C → C
```

预期最终数值：吸引 90、信任 85、舒适 95、冲突 0。

## 已确认的核心范围

- 载体：网页小游戏。
- 单局时长：约 10 分钟。
- 单局题量：最多 10 题，允许中途结束。
- 首发类型：ENTP。
- 关系状态：吸引、信任、舒适、冲突。
- 答题阶段：初识、接触、熟悉、暧昧；相恋只作为结局。
- 选项：每题固定 4 个；同一角色、同一题目、同一选项的数值影响固定。
- 表现：显示模糊进度条和模糊提示，结局页显示准确数值。
- 角色：使用“TA”或“对方”，不设置姓名、性别、取向、职业、立绘和个人经历。
- 基调：清新简约、带黑色幽默、有挑战性，以娱乐为主并提供少量相处启发。
- 商业模式：第一版免费传播。
- 玩家 MBTI 的填写、统计与排名均列入后续 TODO，第一版不提供入口。

## 重要原则

1. 角色表现来自网络流行刻板印象的整理与创作，不代表现实中的所有 ENTP。
2. 每道题必须包含真实的价值取舍或关系冲突，不能只是换皮问卷。
3. 不设置永远正确的处理策略；同一策略对不同 MBTI、不同场景的影响可以不同。
4. 数值用于支撑剧情反馈，不替代剧情本身。
5. 第一版先验证“十题能否形成有趣、可理解、愿意分享的关系体验”，暂不追求完整的 16 型覆盖。
