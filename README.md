# Love with MBTI

一款以 MBTI 流行印象为角色入口的中文网页文字小游戏。玩家选择一位 MBTI 类型的模拟对象，在最多十道带有冲突和取舍的关系情境题中作出选择，观察双方会从初识走向恋爱、朋友、暧昧，还是提前结束关系。

MBTI 在本项目中是传播入口和角色标签，不是心理诊断工具。游戏关注的是：面对鲜明且带有戏剧性的相处模式，玩家如何选择，以及这些选择如何改变双方关系。

## 当前状态

当前代码版本为 `v0.1.0`。截至 2026-09-04，以下 11 种类型已接入网页：

`INTJ`、`ENTJ`、`ESTJ`、`ENTP`、`ENFP`、`ENFJ`、`INTP`、`INFJ`、`INFP`、`ISFJ`、`ISFP`

每种开放类型均包含 10 道题、40 个选项、11 类结局内容、2 类恋爱关系评价和 24 条模糊关系反馈。其余 5 种类型会在选择页显示为“筹备中”。

当前实现包含：

- 类型选择、答题、单题反馈、中途结束和最终结局的完整流程；
- 吸引、信任、舒适、冲突四维关系状态；
- 第 2、5、8 题的阶段门槛，以及第 10 题的最终结局判定；
- 答题过程中的模糊关系计与结局页准确数值；
- 11 个正式 TypeScript 内容包及对应的研究、场景、平衡和可追溯性资料；
- “关系事件记录单”风格的响应式纸张视觉。

项目是纯前端静态应用，不需要后端服务或环境变量。当前不包含账号、排行榜、角色立绘、音效或付费功能。

## 本地运行

需要先安装 Node.js 与 npm，然后执行：

```bash
npm install
npm run dev
```

开发服务器绑定到 `127.0.0.1`。启动后访问终端显示的本地地址，通常为 `http://127.0.0.1:5173`。

## 检查、测试与构建

```bash
npm run check
npm test
node scripts/validate-content.mjs
node scripts/analyze-question-paths.mjs
npm run build
```

- `npm run check`：执行 TypeScript 项目检查。
- `npm test`：运行 Vitest 自动化测试。
- `validate-content.mjs`：检查所有内容包的结构和数值字段。
- `analyze-question-paths.mjs`：为每个开放类型枚举 `4^10 = 1,048,576` 条完整选择路径，检查阶段门槛、结局覆盖和策略路径。
- `npm run build`：执行 TypeScript 检查并生成生产构建，输出位于 `dist/`。

截至 2026-09-04，当前工作区已通过 TypeScript 检查、16 个测试文件中的 84 项测试、内容结构校验、全部 11 种类型的完整路径分析和生产构建。

内容校验仍会报告部分选项“总数值变化超过建议值”的平衡警告；生产构建也会报告单个 JavaScript chunk 超过 500 kB。两类警告目前都不阻塞运行，后续仍需结合试玩与性能优化继续处理。

## 核心范围

- 载体：网页小游戏。
- 单局时长：约 10 分钟。
- 单局题量：最多 10 题，允许中途结束。
- 当前开放类型：INTJ、ENTJ、ESTJ、ENTP、ENFP、ENFJ、INTP、INFJ、INFP、ISFJ、ISFP。
- 关系状态：吸引、信任、舒适、冲突。
- 答题阶段：初识、接触、熟悉、暧昧；相恋只作为结局。
- 选项：每题固定 4 个；同一角色、题目和选项的数值影响固定。
- 表现：过程显示模糊关系计和模糊提示，结局页显示准确数值。
- 角色：使用“TA”或“对方”，不设置姓名、性别、取向、职业、立绘和个人经历。
- 基调：清新简约、带黑色幽默、有挑战性，以娱乐为主并提供少量相处启发。
- 商业模式：当前版本免费传播。

## 内容原则

1. 角色表现来自网络流行刻板印象的整理与创作，不代表现实中的所有同类型人格。
2. 每道题应包含真实的价值取舍或关系冲突，而不是换皮问卷。
3. 不设置永远正确的处理策略；同一策略对不同 MBTI、不同场景的影响可以不同。
4. 数值用于支撑剧情反馈，不替代剧情本身。
5. 当前阶段优先验证各类型的十题能否形成有趣、可理解、愿意分享的关系体验，再逐步扩展到完整的 16 型覆盖。
