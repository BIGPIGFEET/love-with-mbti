# Love with MBTI

**十次选择，你们会走到哪里？**

一款以 MBTI 为灵感的中文关系互动文字游戏。选一位你想认识的对象，从第一次见面开始，在邀约、聊天、独处、争执和关系确认中作出选择，看看你们最终会成为恋人、朋友，还是停在某个没说出口的瞬间。

**[在线体验 → mbti.mzcshan.com](https://mbti.mzcshan.com/)**

## 每一次回应，都在改变关系

游戏收录全部 **16 种 MBTI 类型**，每种类型都有独立的十道情境题与角色回应。每道题提供四种选择：顺着对方、坦诚表达、商量边界，或冒一点风险。相同的相处方式，放进不同的场景，会带来不同的结果。

吸引、信任、舒适与冲突共同推动关系发展。过程中，你只能感受到模糊的变化；走到结局，才能看到这段关系留下的完整数值与评价。有些关系能走完十题，有些会在一次选择后提前散场。

从初识、接触、熟悉到暧昧，游戏设有 **11 类结局**，包含确定关系、危险恋人、成为朋友、悬而未决，以及不同阶段的告别。确定关系后，还会给出进一步的相处评价。

## 一张关系事件记录单

温暖的纸张纹理、墨色文字、陶土色点缀与印章式评价，组成这份可以慢慢读完的关系记录。界面适配手机和桌面，围绕场景、TA 的原话、你的回应与后续反应展开。

直接打开网页即可游玩，无需注册。可以重新挑战同一类型，也可以换一个对象，看看自己的选择会如何改变。

## 关于创作

角色取材于网络上关于 MBTI 的流行印象，并经过戏剧化创作。作品以娱乐和相处体验为主，请把每位角色当作一个虚构对象；现实中的人有各自的经历、边界与表达方式。

## 本地运行

使用 Node.js 22.12+ 与 npm：

```bash
npm ci
npm run dev
```

打开终端显示的本地地址。项目使用 React、TypeScript 与 Vite，构建产物可部署到静态网站托管服务，无需后端或环境变量。

```bash
npm run check  # TypeScript 检查
npm test       # 网站自动化测试
npm run build  # 生成 dist/ 目录
```

## 代码结构

- `src/components/`：类型选择、题目、反馈、关系状态与结局界面。
- `src/content/`：16 种类型的正式题目、结局与内容校验。
- `src/game/`：关系数值、阶段门槛与结局判定。
- `src/assets/`：网站使用的视觉素材。

仓库保留网站源码、自动化测试与构建配置。研究笔记、创作草稿和本地工具资料单独维护。
