# ENTP 行为模型（MVP 创作版）

> 状态：候选模型，供十道互动题设计使用。  
> 依据：[ENTP 网络刻板印象资料库](../docs/research/entp-stereotype-data.md)。  
> 边界：这是“网络如何想象 ENTP”的娱乐化角色模型，不是心理诊断、人格事实或对现实个体的预测。

## 1. 使用规则

- 每道题只选择 2～4 个与情境直接有关的特征，不能把所有特征同时写进 TA；
- 行为必须有可理解的意图和代价：机智可能令人兴奋，也可能让人无处插话；给方案可能是关心，也可能遗漏了感受；
- 玩家不能靠讨好或持续反驳稳定通关。不同策略应分别影响吸引、信任、舒适和冲突；
- A 类特征可构成主行为，B 类只在合适情境中使用，C 类仅用于语气或黑色幽默；
- TA 不因 MBTI 自动失信、冷漠、花心或回避承诺。所有伤害、失约和越界都应由具体行为与后续回应决定。

## 2. 特征层级

### A 类：主要行为驱动

| 代码 | 创作化表达 | 正向用途 | 风险与制约 |
|---|---|---|---|
| F01 | 用追问、反例和拆解推进对话 | 把谈话推向更深的观点交换 | 不把讨论当成情绪场景的默认回应 |
| F02 | 反应快、脑洞多、话题跳转快 | 制造聊天火花和新约会点子 | 给玩家留出节奏与拒绝权 |
| F03 | 偏好变化、新鲜体验和开放可能 | 让相处不单调 | 新鲜感不能替代兑现与告知 |
| F05 | 直率、锋利、玩笑容易越线 | 形成张力和鲜明语气 | 伤人后需要承担影响，不能用“只是玩笑”免责 |
| F06 | 遇事先分析、给方案、实际帮忙 | 展现行动型关心 | 玩家若需要陪伴，应能明确说出需求 |
| F08 | 将思想交流、互相挑战、共同成长视为亲密 | 奖励真诚、有理由的不同意见 | 不把伴侣当成待优化项目 |
| F11 | 对话火花与安全感并不相同 | 让关系进展有层次 | 持续聊天不能自动换算为信任 |
| F12 | 重视自由，关系定义可能后置 | 给边界与承诺议题双方合理立场 | 自由不等于无限模糊或失约 |
| F13 | 抵触控制与预设情感脚本 | 支持双方协商而非命令 | 合理边界不应被污名化为控制 |
| F16 | 偏好安全、有内容的讨论，厌恶破坏性争吵 | 让“辩论者”可被说服、可退出争吵 | 不把一切情绪都叫作不理性 |
| F17 | 可以享受被说服 | 让玩家的论证产生正反馈 | 承认有理不能成为羞辱或压制 |
| F19 | 需要自由也需要被认真对待 | 将承诺落到时间、安排和行动 | 不让口头自由掩盖关系责任 |
| F22 | “冷漠/只会抬杠”是被争议的简化 | 让角色具有反刻板反应 | 不以标签解释所有问题 |
| F24 | 缺少倾听与兑现时，理性和冒险会变成压力 | 支撑失败路径与复盘 | 关注行为后果而非给人格下结论 |

| F15 | 热情可能很快，也可能在熟悉后降温 | 熟悉、暧昧 |

### C 类：只作点缀

F21（“骨折眉”“嘴炮王”等）和 F32（“研究上头、忘记计划”的用户手册式形象）只能服务于台词节奏、黑色幽默或玩家预期；它们不能单独决定数值、结局或道德评价。

## 3. 四阶段行为基线

| 阶段 | TA 的可观察表现 | 关系推进重点 | 禁止的简化 |
|---|---|---|---|
| 初识 | 抛出新话题、轻度挑战常规答案、用玩笑观察反应，可能临时改变小计划。 | 吸引、舒适；玩家是否能保留自己的节奏。 | 不能把高能量直接写成轻浮或攻击。 |
| 接触 | 增加问题、分享灵感、邀请尝试新活动；会观察玩家是否有自己的想法。 | 吸引、信任、舒适；把对话火花转化为尊重。 | 不能把频繁聊天当作已建立亲密。 |
| 熟悉 | 冲突时先分析或给方案；愿意被有理据地说服；开始以行动型关心回应。 | 信任、舒适、冲突；协商支持方式和责任。 | 不能把“解释”写成自动等于“道歉”。 |
| 暧昧 | 火花仍强，关系定义、排他性、自由、兑现和脆弱表达成为焦点。 | 四维共同作用；检验是否能承担明确关系。 | 不能把模糊、退缩或自由需求自动写成不在乎。 |

## 4. 对玩家策略的预期反应

| 玩家策略 | 更可能的正向反应 | 可能的代价或误读 |
|---|---|---|
| 有理有据地提出不同意见 | 吸引与尊重上升，尤其在安全的讨论中。 | 若时机是情绪倾诉，可能降低舒适。 |
| 接住玩笑，同时说清越界处 | 信任上升，冲突可控。 | 过度羞辱或冷处理会触发防御。 |
| 对临时变化提出可执行条件 | 兼顾新鲜感与可靠性。 | 只有禁止、没有协商时会被体验为控制。 |
| 明说“我现在需要倾听/陪伴/方案” | 能减少 F06/F26 的支持错位。 | 只要求对方猜测需求，容易累积冲突。 |
| 提出关系边界与期待 | 若表达具体、可协商，能提升长期信任。 | 以查验、命令或套话推进，会压低舒适。 |
| 认可行动型关心，同时要求对伤害负责 | 能区分意图与影响，建立信任。 | 把“嘴硬心软”当成免责，会放大 F05/F24 的风险。 |

## 5. 冲突维度字典

| ID | 冲突 | 双方合理立场 |
|---|---|---|
| C01 | 新鲜感 vs 可预测性 | 一方不想把关系过成流程；另一方需要基本兑现和提前告知。 |
| C02 | 辩论火花 vs 情绪安全 | 一方用追问探索；另一方需要被听见而非被反驳。 |
| C03 | 坦诚反驳 vs 关系气氛 | 一方重视观点真实；另一方在意时机和公开场合的体面。 |
| C04 | 自由空间 vs 关系确认 | 一方需要自主；另一方需要清晰边界和排他性。 |
| C05 | 解决问题 vs 共情陪伴 | 一方以方案表达关心；另一方需要情绪确认。 |
| C06 | 试探好奇 vs 私人边界 | 一方想多了解；另一方不想被审问。 |
| C07 | 玩笑调情 vs 信号清晰 | 一方享受暧昧互动；另一方需要知道是否被认真对待。 |
| C08 | 挑战规则 vs 尊重共识 | 一方想改进不合理流程；另一方在意共同责任和后果。 |
| C09 | 高峰热情 vs 长期兑现 | 一方追求新的投入；另一方需要稳定的可预期行动。 |
| C10 | 行动型关心 vs 语言型确认 | 一方用行动表达；另一方需要明确回应。 |
| C11 | 被说服 vs 保持面子 | 一方愿意修正观点；另一方担心被公开压制。 |
| C12 | 共同成长 vs 把伴侣当项目 | 一方喜欢互相启发；另一方不愿被评估、改造。 |
| C13 | 解释原因 vs 承担影响 | 一方想说明前因后果；另一方需要先看到歉意与补救。 |
| C14 | 社交热度 vs 低电量边界 | 一方享受高互动；另一方偶尔需要不被误读的独处。 |
