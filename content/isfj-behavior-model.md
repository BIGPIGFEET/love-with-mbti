# ISFJ 行为模型（Stage 02）

> 依据：[ISFJ 网络刻板印象资料库与证据台账](../docs/research/isfj-stereotype-data.md)。
> 边界：这是对“网络如何表征 ISFJ”的证据约束型创作模型，不是人格诊断、现实个体预测或配对规律。阶段位置与具体互动形态是为本项目四阶段关系叙事作出的有界创作推断，不表示任何 ISFJ 必然按此顺序行动。

## 1. 使用规则

- `ISFJ-F01` 至 `ISFJ-F07`、`ISFJ-F10`、`ISFJ-F11` 可支持有边界的可观察互动，但每次必须同时保留建设性潜力、情境风险和直接反例。
- `ISFJ-F08` 只支持拆解“守护者、小护士、妈咪、奶妈、后勤、贤妻良母、爹系、最佳人夫”等角色投射；`ISFJ-F09` 只支持拆解“无聊、浅薄、没创造力、普通 NPC”等贬义标签。两者不直接决定状态、能力、道德、正确答案或关系结果。
- 实际帮助、记住细节、稳定联系、做家务、送礼、触碰、分享日常或讨论未来都不自动等于浪漫兴趣、排他、承诺、同意或忠诚保证。
- 帮助必须允许先询问、拒绝、缩小范围、重新分工和停止；过去自愿完成的任务不能自动变成永久义务，也不能制造未说明的情感债务。
- 含蓄不等于深情，沉默不等于同意，“没事”也不能要求他人读心。关系中的需要、等待期限、暂停和返回方式必须可以被说清、复谈和修改。
- 稳定感不等于守旧、停滞或可操纵。任何计划变化都应根据实际时间、信息、资源和双方意愿处理，而不是用类型判断谁更成熟。
- 不给 TA 补写固定性别、职业、家庭分工、创伤、依恋类型、精神疾病、政治立场或“高阶/低阶”背景；伤害只按具体行动、情境、影响和修复判断。

## 3. 对玩家行动的预期反应

| 玩家行动 | 可能的建设性效果 | 需要保留的风险或限定 |
|---|---|---|
| 如实说明自己想参与、旁听、晚些再聊或更喜欢一对一交流。 | 让社交节奏成为可协商信息，而非性格考试。 | 安静不等于拒绝，健谈也不等于浪漫兴趣；双方都可改变当下选择。 |
| 面对帮助先说明自己是否需要、需要多少，并询问 TA 的容量。 | 防止好意变成代办、义务或隐性债务。 | 玩家可以拒绝不想要的帮助；互惠也不是每次立即等价交换。 |
| 感谢已经发生的具体行动，同时讨论下一次是否继续、如何分工。 | 既看见成本，也避免把过去自愿付出永久化。 | 感谢不能购买未来服务；TA 仍需说出边界，玩家也不能被要求读心。 |
| 对礼物、触碰、陪伴、联系频率和公开程度逐项确认。 | 让表达方式和同意范围都更清楚。 | 接受一种形式不代表接受其他形式或关系升级。 |
| 给需要表达的内容提供低压力入口，并尊重“现在不谈”与约定复谈。 | 兼顾私人整理和双向可见性。 | 低压力不能变成无限等待；追问也不能变成审讯或替对方定义感受。 |
| 对冲突指出具体行为、影响和希望调整之处，并允许有返回安排的暂停。 | 让和谐、直接和修复不再互相排斥。 | 善意不能免责，提出异议也不自动伤害关系；无返回失联不可被美化。 |
| 面对“小护士、老好人、最佳伴侣、无聊传感器、黄金配对”等标签，回到具体兴趣、分工、边界和相处证据。 | 减少类型投射，让关系判断落在现实互动。 | 标签本身不产生奖励；拒绝标签也不应被惩罚或要求证明自己例外。 |

## 6. 证据、推断与限制

- 行为中的“可观察倾向”来自 Stage 01 的在线话语与直接反例；阶段分布、具体触发、谈话入口和修复协议属于有界创作推断，不是 ISFJ 的现实发展顺序。
- 17 个合格 `evidence_source` 来自官方参考、商业类型站、英文 Reddit 社区与少量中文豆瓣自述；同一平台的多帖不算多个独立来源簇，社区材料也不能代表现实人群。
- `surface_record` 中的“小护士、妈咪、奶妈、后勤、爹系、最佳人夫、纯爱、温顺好拿捏、牺牲式爱情”等标签只用于风险护栏，没有进入行为或候选的 `source IDs`。
- `ISFJ-F08` 和 `ISFJ-F09` 只允许生成反标签压力，不得让照顾者或贬义标签本身改变状态。`ISFJ-F10` 的忠诚与长期叙事必须同时带上官方反配对限定和社区互惠要求。
- 爱语、冲突风格、社交能量、情绪开放、边界、稳定需求、记忆力、创造力和承诺意愿均存在直接反例，本模型不建立固定答案。
- 模型不预测玩家与 ISFJ 的兼容性，也不把任何类型当作更适合恋爱、家务、护理、情绪劳动或长期承诺的人。
- ISFJ 当前不在生产可玩类型中；本阶段产物是设计交接，不修改生产注册表、题目、规则、阈值、结局或现有九个内容包。

## 7. Stage-02 交接标准

- 候选事件见 [ISFJ 候选事件库](scenes/isfj-candidate-scenes.md)。
- 上游 ID 集为行为 `ISFJ-B01` 至 `ISFJ-B12`、特征 `ISFJ-F01` 至 `ISFJ-F11`、冲突 `ISFJ-K01` 至 `ISFJ-K13`、符合资格的 Stage-01 `evidence_source`，以及四个运行时状态 ID。
- `ISFJ-F08` 只允许支撑反照顾者角色场景；`ISFJ-F09` 只允许支撑反“无聊/浅薄/无创造力”场景。状态意义只能来自是否尊重具体人、同意、分工、边界、协议与后果。
- Stage 03 只负责筛选、排序和为入选项分配新的 `scene_id`；对白、四项选项、即时反馈、状态数值、阈值与结局均不属于本阶段。
- 正式筛选时应覆盖四阶段，并至少保留一次：社交节奏、帮助许可、照顾者投射、稳定与变化、表达偏好、互惠分工、需要表达、冲突返回、关系定义、能力或配对标签拆解。
