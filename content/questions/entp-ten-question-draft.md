## 使用说明

- 本文件保留为内容设计稿；程序应读取 `src/content` 下的正式数据，不应解析本 Markdown；
- 即时反馈为选择后展示的 TA 反应；模糊提示不显示具体分数；
- 严重公开越界通过四维后果进入统一的结局判定；
- 每题的四个选项按不同策略排序，不能把选项位置与“正确策略”绑定；
- 所有“ENTP 风格”均是研究资料中的网络刻板印象创作加工，不代表现实中的所有 ENTP。

## Q01｜初识｜临时的新地点

**场景**：第一次见面快结束时，TA 突然把手机递到你面前：“附近有家刚开的小店，听说很好吃，但我不确定它现在有没有关门。要不要去碰碰运气？”

**问题**：你会怎么回应？

**冲突**：C01 新鲜感 vs 可预测性  
**研究依据**：F02、F03、F11  
**标签**：`初识` `临时变化` `新鲜感` `可靠性`

| 选项 ID | 策略 | 选择 | 变化（吸/信/舒/冲） | TA 的即时反馈 | 模糊提示 |
|---|---|---|---|---|---|
| q01_go_now | 顺应 | “走啊，关门了就当散步。” | `+10 / -5 / +5 / 0` | TA 马上站起来：“行，我就喜欢这种不怪导航的人。”说完已经开始往门口走。 | “TA被你的冒险劲勾起了兴趣。”；“可靠性似乎留下了一点问号。” |
| q01_keep_original | 坦诚表达 | “我今天有点累，不太想白跑。还是去一家确定开门的吧。” | `-5 / +5 / -5 / +5` | TA 把手机收回来：“也行，至少你不是走到一半才说不想去。”语气听着没生气，只是兴致淡了一点。 | “TA认可你的坦诚。”；“气氛略微变得保守。” |
| q01_make_fallback | 协商解决 | “先打个电话问问。没人接的话，我们就去旁边那家，怎么样？” | `+5 / +10 / +10 / -5` | TA 笑了一声：“可以，你负责兜底，我负责临时起意。” | “TA觉得和你合作很轻松。”；“不确定性被妥善接住了。” |
| q01_turn_into_bet | 冒险玩笑 | “可以，但要是万一关门了，可跟我没关系。” | `+10 / 0 / 0 / +5` | TA 挑了下眉：“行，锅我背，好吃的话功劳也归我。” | “TA对你的反应很有兴趣。”；“计划仍带着一点失控感。” |

**设计理由**：用低风险即兴邀请建立 ENTP 的新鲜感与脑洞感；“协商”不是无条件最优，因为顺应和玩笑能带来更高的即时吸引。

## Q02｜初识｜三个周末方案

**场景**：你们刚聊到周末，TA 一口气发来三张截图：一个临时展览、一场朋友组的桌游局，还有一条郊外徒步路线。“都挺想去的。要不一天塞一个？”

**问题**：你会怎么安排？

**冲突**：C01 新鲜感 vs 可预测性；C14 社交热度 vs 低电量边界  
**研究依据**：F02、F03、F18、F30  
**标签**：`初识` `计划` `社交电量` `表达偏好`

| 选项 ID | 策略 | 选择 | 变化（吸/信/舒/冲） | TA 的即时反馈 | 模糊提示 |
|---|---|---|---|---|---|
| q02_roll_dice | 冒险玩笑 | “你随便说个一到三，我闭眼选，选到哪个就去哪个。” | `+5 / 0 / +5 / 0` | TA 秒回一个“二”，接着问：“等一下，你真的没偷看吧？” | “你们的互动很有火花。” |
| q02_choose_and_reserve | 协商解决 | “这周先选一个，另外两个下次再说。我还想留半天在家躺着。” | `+5 / +10 / +10 / -5` | TA 看了看三张图：“行，那先桌游。剩下两个我先不拿来轰炸你。” | “TA更相信你会把话落到安排上。”；“相处节奏变得舒展。” |
| q02_accept_all | 顺应 | “全去。周末不就是拿来透支的吗？” | `+10 / -10 / -5 / +5` | TA 发来一个握手表情，没过两分钟又问：“你认真点，你到时候不会走一半没电吧？” | “TA被你的热情吸引。”；“节奏开始有些透支。” |
| q02_state_limit | 坦诚表达 | “三个太多了，我最多去一个。不然我后半程肯定开始摆脸色。” | `-5 / +5 / +5 / 0` | TA 愣了一下，随即点头：“这可比你到时候再抱怨好多了。” | “你的边界被听见了。”；“TA仍在适应你的节奏。” |

**设计理由**：Q01 测试临时风险，Q02 测试能否清楚表达时间与精力；两题同属初识，但不重复同一种能力。

## Q03｜接触｜“你确定吗？”

**场景**：聊天时你随口说：“我觉得第一印象一般都挺准的。”TA 马上接了一句：“那要是对方那天刚好状态特别差呢？你还觉得准？”

**问题**：你会怎么接这场讨论？

**冲突**：C02 辩论火花 vs 情绪安全；C03 坦诚反驳 vs 关系气氛  
**研究依据**：F01、F08、F16、F17  
**标签**：`接触` `辩论` `观点` `讨论边界`

| 选项 ID | 策略 | 选择 | 变化（吸/信/舒/冲） | TA 的即时反馈 | 模糊提示 |
|---|---|---|---|---|---|
| q03_request_pause | 坦诚表达 | “你先等一下，别一上来就审我。你自己到底怎么想？” | `+5 / +5 / +10 / -5` | TA 顿了一下：“行，是我问太快了。我觉得第一印象有用，但不能直接判死刑。” | “TA开始调整和你讨论的方式。”；“空气放松了一些。” |
| q03_counter_ridicule | 冒险挑衅 | “你先确定自己听懂我在说什么，再来挑漏洞吧。” | `+5 / 0 / -5 / +15` | TA 眯了下眼：“听懂了才挑的。不然多没意思。”语气里的火药味一下重了。 | “讨论被点燃了。”；“冲突明显升级。” |
| q03_agree_to_end | 顺应 | “也是，你说得对。” | `-5 / 0 / 0 / 0` | TA 等了两秒，发现你真不打算继续，只好说：“好吧，我还以为你会反驳一下。” | “TA的兴趣稍微降了一点。” |
| q03_counter_with_reason | 有理反驳 | “状态差也会留下印象啊。第一印象不一定公平，但不代表它不存在。” | `+10 / +5 / +5 / 0` | TA 笑了：“这句可以。那我换个说法——第一印象到底能不能改？” | “你成功引起了TA的兴趣。”；“TA更愿意认真听你说话。” |

**设计理由**：允许玩家喜欢辩论、拒绝当前强度或结束话题；不把“能反驳”做成唯一正确答案。

## Q04｜接触｜朋友面前的玩笑

**场景**：和一群人聊天时，TA 拿你刚才走错包间的事开玩笑：“幸好是我把人捞回来的，不然 TA 现在可能已经在隔壁吃上了。”大家都笑了，你却不太舒服。

**问题**：你会怎么回应？

**冲突**：C03 坦诚反驳 vs 关系气氛；C07 玩笑调情 vs 信号清晰  
**研究依据**：F05、F09、F18、F21  
**标签**：`接触` `公开边界` `玩笑` `修复`

| 选项 ID | 策略 | 选择 | 变化（吸/信/舒/冲） | TA 的即时反馈 | 模糊提示 |
|---|---|---|---|---|---|
| q04_expose_in_return | 严重反击 | “那你要不要也跟大家说说你上次那件事？”接着把 TA 私下告诉你的糗事说了出来。 | `-5 / -15 / -5 / +20` | TA 脸上的笑一下没了：“这件事我只跟你说过。”TA 不再接你的话，之后的相处明显多了防备。 | “你踩过了明确的私人边界。”；“冲突迅速失去修复空间。” |
| q04_talk_privately | 协商解决 | 当时先不接话，等只剩你们两个人时说：“刚才那句我其实不太舒服，下次别拿这个逗我。” | `+5 / +10 / +10 / 0` | TA 张嘴像是想解释，停了一下又改口：“好，我记住了。刚才是我没看出来。” | “TA开始认真看待你的边界。”；“信任明显上升。” |
| q04_laugh_it_off | 顺应 | 跟着大家一起笑，装作自己完全不介意。 | `+5 / -5 / -5 / 0` | TA 看你也笑了，又顺口补了一句。你没再说什么，TA 也就真当这事没问题。 | “火花仍在。”；“你的舒适感被忽略了。” |
| q04_name_boundary_now | 坦诚表达 | “行了，这个不好笑，换一个。” | `+10 / +5 / +5 / +5` | TA 卡了一下，马上把话题拐走。人散后，TA 低声问你：“刚才是真生气了？” | “边界被清楚说出。”；“短暂摩擦没有失控。” |

**设计理由**：TA 开玩笑不是自动错误；玩家以泄露隐私、公开羞辱进行严重反击时，主要重创信任并把冲突推高，吸引与舒适只承担连带损伤，再由统一规则判定关系走向。

## Q05｜接触｜这算不算特殊

**场景**：TA 刚在聊天框里说你“今天反应还挺可爱”，转头又在群里和别人聊得一样热闹。你盯着那句话看了半天，还是没弄明白自己到底算不算特殊。

**问题**：你会如何处理这份不确定？

**冲突**：C07 玩笑调情 vs 信号清晰  
**研究依据**：F09、F11、F18、F29  
**标签**：`接触` `暧昧信号` `观察` `澄清`

| 选项 ID | 策略 | 选择 | 变化（吸/信/舒/冲） | TA 的即时反馈 | 模糊提示 |
|---|---|---|---|---|---|
| q05_keep_playing | 顺应 | 当没看出区别，继续跟 TA 互相开玩笑，谁也不提那句话。 | `+10 / -5 / 0 / 0` | TA 很快又接了你三个梗，还单独给你发了个表情包。热闹是真的，答案还是没有。 | “TA被你的节奏吸引。”；“关系信号仍然模糊。” |
| q05_withdraw_silently | 保留距离 | 慢慢少回一点，不再接那些容易让人多想的话。 | `-5 / +5 / +5 / 0` | TA 连续两次没等到你的回应，之后也没再往暧昧的方向说，只问了一句：“最近很忙？” | “距离被拉开了。”；“表面相处仍算平稳。” |
| q05_demand_answer | 直接施压 | “你别绕了，现在就说，你到底是不是喜欢我？” | `+5 / 0 / -5 / +15` | TA 看了很久才回：“你这问题怎么还有限时作答？”后面跟了个笑脸，但没正面回答。 | “关系被迫加速。”；“舒适感有所下降。” |
| q05_invite_with_clarity | 协商解决 | “我还挺喜欢和你聊天的。要不下次就我们两个见？见完再看。” | `+10 / +10 / +10 / -5` | TA 回得很快：“行。那这次不带观众，也不给你装没看懂的机会。” | “TA更愿意给出可观察的回应。”；“你们之间多了一点信任。” |

**设计理由**：这一题不要求玩家立即得到告白，而是区分“明确下一步”与“逼出立即结论”。

## Q06｜熟悉｜先听我说，还是先帮我解决？

**场景**：你跟 TA 说，今天开会时准备了很久的方案被人一句话否掉了。TA 听到一半就拿出手机：“等一下，这事能拆。你明天先去找——”

**问题**：你现在需要什么？

**冲突**：C05 解决问题 vs 共情陪伴；C10 行动型关心 vs 语言型确认  
**研究依据**：F06、F07、F20、F26  
**标签**：`熟悉` `情绪支持` `解决方案` `需求表达`

| 选项 ID | 策略 | 选择 | 变化（吸/信/舒/冲） | TA 的即时反馈 | 模糊提示 |
|---|---|---|---|---|---|
| q06_reject_logic | 对抗 | “你能不能别一开口就教我做事？我不是来听你上课的。” | `-10 / 0 / -10 / +15` | TA 把手机扣到桌上：“我是在帮你想办法，不是在给你批作业。”两个人的语气都硬了起来。 | “双方都觉得没有被理解。”；“冲突明显上升。” |
| q06_take_solution | 顺应 | “行，你帮我理一下吧。我现在脑子真的挺乱的。” | `+5 / +5 / -5 / 0` | TA 马上把事情分成了三步，还顺手给你列了明天能发的消息。办法是有了，你心里还是堵着。 | “TA用行动回应了你。”；“有些感受仍没有被安放。” |
| q06_ask_for_presence | 坦诚表达 | “我知道你想帮我，但我现在不想解决。你先陪我坐会儿行吗？” | `+5 / +10 / +10 / -5` | TA 看了你一眼，把手机放下：“行。那我先不说，你想骂谁就骂谁。” | “你的需要被清楚接住。”；“TA对你更放松了。” |
| q06_sequence_needs | 协商解决 | “先让我吐槽十分钟，等我缓过来你再帮我想怎么办。” | `+5 / +5 / +10 / 0` | TA 看了眼时间：“好，十分钟。第十一分钟我再开始多管闲事。”然后真没打断你。 | “你们找到了共同的节奏。”；“舒适感上升。” |

**设计理由**：两条正向路径分别奖励清晰表达和可执行协商；接受方案也不是错，只是会留下情绪未被回应的代价。

## Q07｜熟悉｜不合理的规则

## Q09｜暧昧｜自由和排他性

**场景**：你们已经连续几周单独见面。你问 TA，现在是不是可以不再和别人发展同样的关系。TA 安静了一会儿：“我是在乎你，但我不想以后去哪、见谁都要报备。你想确认的到底是什么？”

**问题**：你会怎么回答？

**冲突**：C04 自由空间 vs 关系确认  
**研究依据**：F12、F13、F19、F23、F29  
**标签**：`暧昧` `关系定义` `自由` `排他性`

| 选项 ID | 策略 | 选择 | 变化（吸/信/舒/冲） | TA 的即时反馈 | 模糊提示 |
|---|---|---|---|---|---|
| q09_keep_ambiguous | 顺应 | “好吧，那就先不说。反正现在这样也挺开心的。” | `+15 / -5 / 0 / +5` | TA 明显松了口气，伸手碰了下你的杯子：“那就先开心。”这个问题也就这么被放回了原处。 | “吸引被重新点燃。”；“关系仍缺少清晰的落点。” |
| q09_control | 强制控制 | “很简单，以后不许再跟别人单独出去。做不到就是不够在乎我。” | `-10 / -10 / -20 / +20` | TA 的脸色一下沉了：“那你不是在问我，你是在通知我。”TA 往后靠了靠，连解释的兴趣都没了。 | “信任和舒适明显下降。”；“冲突正在失控。” |
| q09_trial_agreement | 协商解决 | “我想要的是别再和别人发展暧昧，不是查你行程。我们先这样试一个月，有不舒服就直接说。” | `+15 / +15 / +10 / -5` | TA 追问了几句哪些算暧昧，最后点头：“可以。至少这次规则是我们一起定的。” | “TA愿意和你一起定义边界。”；“信任显著上升。” |
| q09_state_boundary | 坦诚表达 | “我喜欢你，但我没办法一直这样猜。你没想好之前，我会少投入一点。” | `-10 / +10 / +15 / 0` | TA 没有马上挽留，只低头转了转杯子：“我知道了。给我一点时间，但我不会当你没说过。” | “你的边界被认真对待。” |

**设计理由**：让“确认关系”和“保留自主”都可以被合理表达；高吸引的模糊选项不自动等于好结局。

## Q10｜暧昧｜把火花变成日常

**场景**：最近你们见面的频率没刚开始那么高。TA 翻着聊天记录说：“我们是不是每次都要等谁突然想到一个特别有意思的事才见面？这么下去，哪天两个人都没点子就直接失联了。”

**问题**：你会如何回应这段关系的下一步？

**冲突**：C09 高峰热情 vs 长期兑现  
**研究依据**：F03、F15、F19、F24、F25、F27  
**标签**：`暧昧` `长期维护` `兑现` `新鲜感` `最终题`

| 选项 ID | 策略 | 选择 | 变化（吸/信/舒/冲） | TA 的即时反馈 | 模糊提示 |
|---|---|---|---|---|---|
| q10_chase_thrill | 冒险升级 | “那就每周都找个没做过的事。只要够刺激，就不会没话聊。” | `+10 / 0 / -5 / +15` | TA 先说了句“听着很爽”，又皱起眉：“可我们哪周都累得不想动呢？直接停更？” | “吸引明显上升。”；“关系的压力也在累积。” |
| q10_fix_everything | 坦诚但僵硬 | “以后固定每周同一天见，谁都别改。省得每次临时想。” | `-10 / +5 / -5 / +5` | TA 想了一会儿：“可以是可以。但每周同一天、同一个地方，也太像打卡了吧。” | “TA认可你的确定性。”；“相处的舒展感有所下降。” |
| q10_flexible_ritual | 协商解决 | “每周先留一个晚上给彼此，具体做什么轮流想。真有事就提前说，别临时消失。” | `+20 / +10 / +10 / 0` | TA 拿起手机翻日历：“那我先占下周四。做什么归我想，你不许提前套话。” | “关系被明确推进。”；“信任与舒适明显上升。” |
| q10_let_it_drift | 回避 | “想见的时候再约呗。真没话聊了，散了也正常。” | `-5 / -5 / 0 / 0` | TA 看了你一会儿，只回了句：“也是。”然后把刚打到一半的下次计划删掉了。 | “关系暂时没有冲突。”；“但也没有获得新的支点。” |

**设计理由**：最终题不直接问“要不要恋爱”，而是检验吸引是否能转化为承诺、安排和兑现；这为确认恋爱、危险恋人、朋友与暧昧未决提供不同路径。
