# INTP 正式十场景策展交接

> 状态：正式场景主题、职责与顺序已锁定；完整题目草案见 [INTP 正式十题内容草案](../questions/intp-ten-question-draft.md)，初始数值尚待全路径平衡。  
> 依据：[候选场景库](intp-candidate-scenes.md)、[INTP 行为模型](../intp-behavior-model.md)、[研究证据台账](../../docs/research/intp-stereotype-data.md)、[核心规则](../../docs/02-core-rules.md)。

## 1. 策展约束与判断

- 正式数量固定为 10，阶段严格使用 `first_meeting 2 / contact 3 / familiarity 3 / ambiguity 2`；
- 关系弧从“能否接住一种不标准的认识方式”，推进到“能否处理节奏、支持、责任与修复”，最终落到“是否共同定义并维护关系”；
- 每场只锁定可观察触发、主要测试和选择压力，不在本阶段写最终台词、选项、数值或反馈；
- 十场的主要冲突不重复；F12“明确表达”和 F13“个人责任”可以多次作为次级护栏，但不得变成玩家单向适配 TA 的通关公式；
- C 类 F14、F17、F18 不驱动正式场景，不把“机器人、猫系、使用/饲养手册”等包装当人格事实；
- 正式序列没有沿用候选库的第一轮推荐：EV05 与 EV02 相邻会连续测试“接信息/兴趣分享”，因此用 EV09 替换 EV05；结尾用 EV19→EV21 形成“定义关系→维护时间结构”的递进，避免连续两题都只问语言确认。

## 6. 终止能力

只有 `INTP-S07` 被标为条件性 terminal-capable。终止原因必须来自玩家的明确严重行为，例如在被公开纠正后，为报复而泄露 TA 的私人信息、煽动旁人围攻或实施持续公开羞辱；不能因为 TA “像 INTP”、说话直接或一次纠正本身终止关系。

普通的当场制止、私下指出影响、要求道歉、离开现场或决定不再继续关系，都不应被剧情指定为 `blocked_immediately`。运行时校验器现已泛化为“每套十题最多一个剧情指定结束选项”，可以承载 INTP-S07；是否最终保留这个 terminal 位置，仍要在写选项阶段根据具体玩家行为确认。

## 8. 阶段、难度与叙事节奏

| 阶段 | 场景职责 | 难度变化 | 门槛意义 |
|---|---|---|---|
| 初识 Q01～Q02 | 话题边界、低压力续联、兴趣互惠、信号不过度解读 | 低→低中 | Q02 后的信任与舒适来自真实参与和边界，不来自盲目迎合。 |
| 接触 Q03～Q05 | 分歧协议、联络节奏、决定与兑现 | 中→中高 | Q05 后检验是否形成可持续相处方式，而不只是在聊天上有火花。 |
| 熟悉 Q06～Q08 | 情绪支持、公开影响、冲突暂停与修复 | 中高→高 | Q08 后的吸引不能绕过信任、舒适和冲突管理。 |
| 暧昧 Q09～Q10 | 关系定义、排他/公开协议、独立与固定投入 | 很高→很高 | 第十题结束时可以据双方的明确协议与维护能力进入最终结局判断。 |

节奏刻意交替为：奇异但轻松的讨论 → 低压力分享 → 观点协商 → 联系摩擦 → 实际安排 → 私人脆弱 → 公开影响 → 冲突修复 → 关系定义 → 日常维护。没有连续两题把“会辩论”“会给空间”或“会准确说需求”当作同一个考试。

## 9. 追踪、风险与替换日志

### 9.1 来源追踪

- 每个正式场景均保留候选 EV ID、特征 ID、冲突 ID 和至少两个研究来源 ID；
- 研究来源支持的是网络叙事和创作机制，不支持现实 INTP 的行为概率；
- 小红书 S35、S36、S39 只补充中文情境、分歧和反例，没有生成新的 A 类特征；
- 后续写题时 `researchRefs` 应从本文件的候选资格表复制，不可只引用标题级 S32、病理化标题 S37 或 C 类 F18。

### 9.2 未解决风险

- INTP-S01 的反事实问题如果写得过于工整，会像人格测试题而不像约会对话；写题阶段应保持自然但不改变“思想火花 vs 轻松在场”的职责；
- INTP-S03 是元沟通场景，需避免把 TA 写成提前朗读关系守则；最终触发应来自一次具体的小分歧；
- INTP-S04 的“两天”只是当前事件尺度，不得被写成所有 INTP 的标准回复周期；
- INTP-S07 的 terminal 预留已获得通用结构支持；写题阶段仍须确保唯一 terminal 来自玩家主动实施的严重越界，而不是 TA 的类型或一次普通分歧；
- INTP-S08 必须让后续兑现影响信任；如果题目只问玩家是否“给空间”而不检查 TA 是否返回，就会奖励单向适配；
- INTP-S09 与 INTP-S10 必须有叙事连续性：前者先形成至少一项共同协议，后者才能讨论稳定维护；
- 十题已覆盖全部 A 类特征与冲突家族，但这不等于心理代表性；正式文案仍需保留个体差异和退出不兼容关系的正当性。
