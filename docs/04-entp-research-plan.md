# ENTP 网络刻板印象数据收集计划

## 1. 研究目标

广泛收集网络上关于 ENTP 的高频描述、段子、相处经验和争议印象，将其整理为可用于十道恋爱互动题的行为模型。

研究对象是“网络如何理解和想象 ENTP”，不是证明这些描述具有心理学真实性。

## 2. 信息范围

以中文互联网为主要样本，其他语言互联网作为补充和对照。

优先收集：

- ENTP 自述；
- 与 ENTP 相处者的描述；
- ENTP 恋爱、暧昧、约会和聊天相关讨论；
- 对 ENTP 的正面、负面和矛盾评价；
- 高频梗、刻板印象和反刻板印象；
- 不同平台反复出现的相似行为描述。

需要区分：

- MBTI 基础概念或官方类型描述；
- 网络高频刻板印象；
- 单个用户的个人经历；
- 为游戏效果进行的创作加工。

## 3. 建议搜索主题

研究时至少覆盖以下方向：

- ENTP 给人的第一印象；
- ENTP 如何开启和维持聊天；
- ENTP 喜欢一个人的表现；
- ENTP 暧昧期行为；
- ENTP 会被什么吸引；
- ENTP 讨厌哪些交流方式；
- ENTP 如何辩论、试探和开玩笑；
- ENTP 对计划、变化和新鲜感的态度；
- ENTP 对规则、权威和边界的反应；
- ENTP 如何处理情绪表达和承诺；
- 与 ENTP 相处容易产生的冲突；
- ENTP 刻板印象中最被夸张或最有争议的部分。

## 4. 证据记录格式

每条候选特征应记录：

| 字段 | 说明 |
|---|---|
| 特征描述 | 用中立语言概括观察到的刻板印象 |
| 来源链接 | 可复查的原始页面 |
| 平台与语言 | 判断样本环境 |
| 来源类型 | 自述、他人评价、段子、文章或讨论 |
| 倾向 | 正面、负面、中性或矛盾 |
| 频率 | 单点、重复出现或跨平台高频 |
| 恋爱相关性 | 是否能转化为初识到暧昧阶段的行为 |
| 冲突潜力 | 是否能形成合理取舍，而不是单纯好坏 |
| 可信备注 | 是否可能只是个例、营销内容或重复搬运 |

不因某条内容有趣就直接写入角色模型。核心特征原则上应有多个相互独立的来源支持，或者明确标记为“低频但适合创作的网络梗”。

## 5. 特征分级

研究结果分为三层：

### A. 核心高频特征

跨平台重复出现，且能够稳定影响多个场景。用于构成 ENTP 的主要行为模型。

### B. 情境特征

只在辩论、计划、暧昧、情绪表达等特定条件下出现。用于设计具体题目。

### C. 戏剧化梗

辨识度高、传播性强，但夸张或证据有限。可以少量用于黑色幽默，不能当作所有题目的基础。

## 6. 研究产物

数据收集完成后应产出：

1. ENTP 高频刻板印象清单；
2. ENTP 正面、负面和矛盾评价对照表；
3. ENTP 在初识、接触、熟悉、暧昧阶段的行为表现；
4. ENTP 偏好的回应方式与常见雷区；
5. 至少十个候选冲突维度；
6. 至少十五个候选场景；
7. 每个场景可使用的来源和创作加工说明；
8. 最终用于 MVP 的十题选择理由。

## 7. 研究完成标准

只有满足以下条件后才开始正式写十道题：

- 核心特征不是来自单一平台或单一作者；
- 正面和负面描述均被纳入；
- 能解释 ENTP 为什么会喜欢或反感某种回应；
- 能为四个关系阶段分别提供自然场景；
- 能形成至少十个双方均有合理立场的冲突；
- 明确哪些部分是网络共识、哪些是游戏创作。
