# MVP 路线图

## 阶段 0：规则确认

当前文档固化以下内容：

- 产品定位和第一版范围；
- 四维关系状态；
- 固定十题和阶段门槛；
- 中途结束与五类最终结局；
- 题目、选项和反馈的数据规范；
- ENTP 网络资料研究方法。

完成标志：文档中的规则不存在互相冲突的定义，所有未开发内容明确列入 TODO。

## 阶段 1：ENTP 数据收集

1. 广泛搜索中文互联网资料；
2. 使用其他语言资料补充和对照；
3. 按统一表格保存来源和特征；
4. 对特征去重、分级并记录争议；
5. 产出 ENTP 网络刻板印象行为模型。

完成标志：能够用证据说明 ENTP 集合体在四个关系阶段中如何行动、喜欢什么、反感什么。

## 阶段 2：十题内容设计

1. 从研究结果中选出约十个冲突维度；
2. 建立十五个以上候选场景；
3. 选出覆盖四个阶段的固定十题；
4. 为每题编写四个选项、即时反馈和模糊提示；
5. 为所有选项配置固定数值；
6. 编写中途结局和最终结局卡片文案。

完成标志：不依赖程序即可在表格或文档中完整跑通一次游戏。

## 阶段 3：规则平衡

1. 枚举或模拟大量选择组合；
2. 验证阶段门槛与所有结局可达；
3. 检查是否存在固定万能策略；
4. 调整数值变化和门槛；
5. 邀请少量目标用户进行盲测。

完成标志：玩家能理解结果，且不同策略能够产生明显但合理的差异。

## 阶段 4：网页 MVP 开发

开发范围：

- 首页和玩法说明；
- 十题流程；
- 四选一交互；
- 四维状态计算；
- 阶段和提前结束判断；
- 模糊进度条与反馈；
- 结局卡片；
- 重新挑战；
- 基础移动端适配。

完成标志：无需账号即可在常见手机和桌面浏览器完成一局。

## 阶段 5：测试与发布

- 功能和兼容性测试；
- 文案错别字与语气检查；
- 题目路径和结局回归测试；
- MBTI 娱乐化声明；
- 基础访问统计；
- 免费公开发布。

## 第二版计划

- 为每个阶段增加备用题库；
- 从固定十题改为分阶段半随机抽取；
- 扩展到四种辨识度明显的 MBTI；
- 允许主题 UI 随 MBTI 变化；
- 增加更多中途特殊结局和分享文案。
